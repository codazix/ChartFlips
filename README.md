# ChartFlips

    ChartFlips is a public forex market analysis platform for traders who want clear, interactive chart-based insights.

    **Live website:** https://chartflips.com

    ## About Codazix

    ChartFlips is operated by **Codazix LLC**.

    ## TradingView integration

    ChartFlips is applying to use the TradingView Advanced Chart Library to provide interactive market charts and technical analysis tools to its users through the public ChartFlips platform.

    This repository is the public project page for ChartFlips and its planned charting integration.
